Structured Storage Architecture
Solved Problem

To solve the utility company's problem of unorganized, chaotic meter records, SMRS stores readings in a relational time-series table (meter_readings) with foreign key constraints, automated indexing, and indexed timestamps.

PRIMARY KEY reading_id (Auto)
FOREIGN KEY meter_id → meters
TIME-OF-USE INDEX (meter_id, timestamp)
Key Benefits Over Unstructured Files:
  • Atomic Ingestion: Zero record loss or duplicate calculation issues.
  • Peak-Hour Flagging: Real-time categorization of ToU units for billing tariffs.
  • Sub-second Load Analysis: Instantaneous 24-hr aggregation by Feeder for load planning.
  • Automated Anomaly Detection: Immediate alerts for abnormal voltage drops, zero-draw, or tampering.
