Problem Statement & Core Solution

"A utility company has no structured storage for meter readings, complicating billing and load planning."

How SMRS Solves This Challenge:

Replaces messy spreadsheets and flat-files with structured MySQL schemas (meters, meter_readings, consumers, tariffs, billing_records). Every reading records exact timestamp, active kW, cumulative kWh, voltage, current, power factor, and peak flags with foreign key integrity.

Eliminates delayed and estimated bills. Calculates energy charges using multi-tier slabs, Time-of-Use (ToU) peak surcharges during high grid strain hours, fixed connection fees, and government taxes.

Aggregates time-series readings into 24-hour load curves, peak demand windows, load factor metrics, and feeder capacity utilization bars (Chart.js) to prevent transformer trips and plan infrastructure upgrades.
Technical Stack Implementation
Flask (Python) Modular backend router, REST API engine, tariff and load planning business logic.
MySQL Database Structured relational schema in schema.sql, with smart fallback to SQLite for instant local execution.
REST API Standard JSON endpoints for AMI smart meter ingestion, batch telemetry, billing and analytics.
Chart.js Interactive dynamic 24-hr system load profiles, feeder transformer bars, category share doughnuts.
Bootstrap 5 Responsive grid layout, modern cards, offcanvas, modals, and flexible navigation.
HTML5, CSS & JS Asynchronous fetch calls, live telemetry stream simulator, sleek utility dark dashboard aesthetics.
REST API Documentation
JSON API
POST /api/readings/ingest

Ingest single smart meter telemetry packet into structured storage.

{
  "meter_id": "SM-N-101",
  "cumulative_kwh": 642.50,
  "active_power_kw": 3.20,
  "voltage_v": 231.2,
  "current_a": 14.3,
  "power_factor": 0.96,
  "tamper_alert": false
}
GET /api/analytics/load-curve

Retrieves 24-hr hourly kW demand array, peak demand (kW), and load factor (%) for grid planning.

GET /api/analytics/feeder-capacities

Calculates transformer capacity percentage, current kW load vs rated threshold per Feeder.

POST /api/billing/generate

Trigger automated billing engine for all smart meters for a given month.

{
  "billing_month": "2026-09"
}
POST /api/simulator/tick

Simulates real-time telemetry pulse across all active grid smart meters with time-of-day load profiles.
